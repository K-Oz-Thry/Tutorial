# Tutorial
Repository for my honors project, a tutorial on how to portray multivariable graphics

Tutorial #1 = Basic static multivariable graphics
- We use the Matplotlib & Seaborn to start off with basic knowledge and skills of how multivariable graphics work. 

Tutorial #2 = Interactive multivariable graphics
- We use Holoviews/Bokeh and Plotly to take an interesting smaple spin on multivariable graphics
